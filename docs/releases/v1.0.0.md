Erste Version des **CTk Builder** – GUIs für [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) per Drag & Drop im `grid()`-Layout bauen und als sauberen Python-Code exportieren.

## Downloads

| System | Datei | Starten |
|---|---|---|
| macOS (Apple Silicon) | `CTk-Builder-1.0.0-macOS-AppleSilicon.zip` | entpacken, `CTk Builder.app` in „Programme“ ziehen |
| Windows | `CTk-Builder-1.0.0-Windows.exe` | doppelklicken |
| Linux | `CTk-Builder-1.0.0-Linux.tar.gz` | entpacken, `./ctk-builder` |
| Python (alle Systeme) | `ctk_builder-1.0.0-py3-none-any.whl` | `pip install ctk_builder-1.0.0-py3-none-any.whl`, dann `ctk-builder` |

Die Apps bringen Python und CustomTkinter mit – es muss nichts installiert werden, auch „▶ Ausführen“ funktioniert direkt.

**Erster Start:** Die Apps sind nicht signiert.
- **macOS:** Beim ersten Öffnen erscheint eine Warnung. Unter *Systemeinstellungen → Datenschutz & Sicherheit* auf **„Trotzdem öffnen“** klicken – oder im Terminal:
  `xattr -dr com.apple.quarantine "/Applications/CTk Builder.app"`
- **Windows:** Bei „Der Computer wurde durch Windows geschützt“ auf **„Weitere Informationen“ → „Trotzdem ausführen“** klicken.

## Funktionen

- Widgets: Label, Button, Entry, Textbox, CheckBox, Switch, RadioButton, Frame (beliebig verschachtelbar)
- Drag & Drop aus der Palette, Verschieben und Tauschen auf der Arbeitsfläche, neue Zeilen/Spalten am Rand
- Zeilen-/Spaltenköpfe mit `weight`, `minsize`, `uniform`; Kontextmenü zum Einfügen und Löschen
- Eigenschaften-Panel mit Prüfung aller Eingaben, Rückgängig/Wiederholen für jede Änderung
- Export in zwei Dateien: `<name>_ui.py` (wird überschrieben) und `<name>.py` für eigene Logik (wird nie überschrieben)
- „▶ Ausführen“ startet das exportierte Programm, Ausgaben erscheinen im Builder
- Moderne Oberfläche mit hellem und dunklem Modus
