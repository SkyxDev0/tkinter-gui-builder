Fehlerbehebungen für das freie Platzieren aus 1.1.0 – bitte statt 1.1.0 verwenden.

## Behoben

- **Kein Einfrieren mehr beim Umschalten auf „Raster“.** Ab etwa zwölf bündig ausgerichteten Widgets rechnete der Builder beim Umstellen auf „Raster“ minutenlang und reagierte nicht mehr. Jetzt dauert das auch bei vielen Widgets nur Millisekunden.
- **Ziehen direkt nach einer Pfeiltaste** funktioniert. Bisher ging das Ziehen verloren, wenn es weniger als eine knappe halbe Sekunde nach dem Verschieben mit den Pfeiltasten begann.
- **Nach Esc oder Strg+Z während des Ziehens** blieb manchmal die nächste Größenänderung hängen und übernahm danach das Ziehen eines anderen Widgets. Behoben.
- Ein abgebrochenes Ziehen, das über der Werkzeugleiste losgelassen wurde, löste dort **Löschen oder Duplizieren** aus. Knöpfe reagieren jetzt nur noch, wenn auch das Drücken auf ihnen begann.
- Ein **zweiter Klick kurz nach dem ersten** startet jetzt ein Ziehen (bisher als Doppelklick ignoriert).
- Ein Widget, das aus einem Frame über den Fensterrand hinaus gezogen wird, bleibt im Fenster, statt in den Frame zurückzuspringen.
- **Klick in der Palette** legt das neue Widget nicht mehr auf ein vorhandenes, sondern darunter.
- Nach dem Ablegen wirken **Pfeiltasten und Entf** sofort, ohne erst auf das Widget zu klicken.
- Eine gerade mit den Pfeiltasten gemachte Bewegung zählt als ungespeicherte Änderung: **Neu, Öffnen und Beenden fragen nach.** Gedrückt gehaltene Pfeiltasten ergeben zuverlässig einen einzigen Rückgängig-Schritt.
- Ein Widget, das aus „Frei“ in eine Rasterzelle kommt, übernimmt keine alten Spans oder Abstände mehr. Ein im Raster gestrecktes Widget behält beim Herausziehen seine sichtbare Breite.
- **Reihenfolge per Tastatur** jetzt mit `Strg+↑` / `Strg+↓` (mit `Shift`: ganz nach vorne/hinten), auch auf deutscher Tastatur. „Alles frei anordnen“ steht zusätzlich im Menü „Bearbeiten“.
- Verschieben per Pfeiltasten und Ablegen zeichnen die Fläche nicht mehr komplett neu: flüssiger, besonders bei vielen Widgets.

## Downloads

| System | Datei | Starten |
|---|---|---|
| macOS (Apple Silicon) | `CTk-Builder-1.1.1-macOS-AppleSilicon.zip` | entpacken, `CTk Builder.app` in „Programme“ ziehen |
| Windows | `CTk-Builder-1.1.1-Windows.exe` | doppelklicken |
| Linux | `CTk-Builder-1.1.1-Linux.tar.gz` | entpacken, `./ctk-builder` |
| Python (alle Systeme) | `ctk_builder-1.1.1-py3-none-any.whl` | `pip install ctk_builder-1.1.1-py3-none-any.whl`, dann `ctk-builder` |

**Erster Start:** Die Apps sind nicht signiert.
- **macOS:** Beim ersten Öffnen erscheint eine Warnung. Unter *Systemeinstellungen → Datenschutz & Sicherheit* auf **„Trotzdem öffnen“** klicken – oder im Terminal:
  `xattr -dr com.apple.quarantine "/Applications/CTk Builder.app"`
- **Windows:** Bei „Der Computer wurde durch Windows geschützt“ auf **„Weitere Informationen“ → „Trotzdem ausführen“** klicken.
